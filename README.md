# ربات تلگرام دانلود از یوتیوب و اینستاگرام

ربات خصوصی دانلود ویدیو: لینک یوتیوب یا اینستاگرام بفرستید، ویدیو را دانلود می‌کند و همین‌جا تحویل می‌دهد.

## امکانات

- دانلود ویدیوی یوتیوب (حداکثر ۷۲۰p) و پست/ریلز اینستاگرام با `yt-dlp`
- سقف ارسال ۴۵ مگابایت (محدودیت ربات تلگرام ۵۰ مگابایت است)؛ اگر ویدیو بزرگ‌تر باشد، نسخه صوتی mp3 فرستاده می‌شود
- پست عکس اینستاگرام به‌صورت عکس فرستاده می‌شود
- فقط یک دانلود هم‌زمان (برای اینکه هاست کوچک رایگان زیر بار نرود)
- ربات خصوصی است: اولین نفری که `/start` بفرستد مالک می‌شود و بقیه پیام «ربات خصوصی است» می‌گیرند
- پیام‌های وضعیت (در حال دانلود… / در حال ارسال…) و پیام خطای فارسی صادقانه
- دکمه‌های درون‌خطی دوزبانه (فارسی / English): منوی شروع (راهنما، زبان) و انتخاب فرمت بعد از فرستادن لینک (ویدیو / صوتی MP3)؛ زبان از دکمه 🌐 عوض می‌شود و در `data/lang.json` ذخیره می‌ماند

## اجرای محلی

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

export BOT_TOKEN="توکن ربات از BotFather"
python bot.py
```

توکن را از **BotFather** در تلگرام بگیرید (`/newbot`). توکن را هرگز داخل کد یا فایل ننویسید؛ فقط از متغیر محیطی خوانده می‌شود.

## کوکی (یوتیوب و اینستاگرام)

دانلود از یوتیوب و اینستاگرام بدون ورود به حساب، از روی سرورها معمولاً محدود است:

- **یوتیوب** از آی‌پی دیتاسنترها (مثل هاست‌های ابری) درخواست ورود می‌کند
  («Sign in to confirm you're not a bot») و بدون کوکی دانلود نمی‌دهد.
- **اینستاگرام** هم برای خیلی از پست‌ها ورود به حساب می‌خواهد.

برای اینکه دانلود هر دو بهتر کار کند:

1. کوکی‌های نشست یوتیوب/اینستاگرام را در قالب Netscape در فایل `data/cookies.txt` بگذارید
   (با افزونه مرورگر مثل «Get cookies.txt LOCALLY» می‌توانید خروجی بگیرید).
2. ربات را دوباره اجرا کنید؛ اگر فایل وجود داشته باشد، به‌صورت خودکار استفاده می‌شود.

توجه: استفاده از کوکی حساب شخصی ممکن است باعث محدودشدن آن حساب شود؛ بهتر است از یک حساب جدا استفاده کنید.

## استقرار روی FadeHost (رایگان)

FadeHost برای ربات تلگرام مناسب است چون پلن رایگان آن **نمی‌خوابد** و **کارت بانکی نمی‌خواهد**.

1. در [fadehost.com](https://fadehost.com) ثبت‌نام کنید.
2. یک اپ Python بسازید و آن را به این مخزن GitHub متصل کنید.
3. متغیرهای محیطی را تنظیم کنید:
   - `BOT_TOKEN` = توکن ربات از BotFather
   - `BOT_DATA_DIR` = `/data` (داده‌ها زیر `/data` می‌مانند و با Deploy پاک نمی‌شوند)
4. اپ را Deploy کنید. ربات با polling اجرا می‌شود و همیشه روشن می‌ماند.

نکته: فایل `data/owner.json` (مالک ربات) داخل کانتینر ذخیره می‌شود؛ اگر سرویس را دوباره Deploy کنید، مالک باید دوباره با `/start` خودش را ثبت کند. اگر فایل کوکی دارید، آن را به‌صورت Secret/Volume اضافه کنید یا قبل از Deploy در پوشه `data/` بگذارید.

## ساختار

```
bot.py            کد اصلی ربات
requirements.txt  وابستگی‌های پایتون
Dockerfile        ایمیج داکر (python:3.12-slim + ffmpeg)
data/             owner.json و cookies.txt اختیاری (در زمان اجرا ساخته می‌شوند)
```

## محدودیت‌های شناخته‌شده

- سقف ارسال فایل با Bot API تلگرام ۵۰ مگابایت است؛ ربات برای اطمینان روی ۴۵ مگابایت قفل شده است.
- **یوتیوب بدون کوکی معمولاً از روی سرور دانلود نمی‌دهد** (تست‌شده در نوامبر ۲۰۲۶:
  یوتیوب از آی‌پی ماشین مجازی درخواست ورود کرد و دانلود رد شد). با گذاشتن
  `data/cookies.txt` مشکل حل می‌شود.
- اینستاگرام بدون کوکی برای پست‌های عمومی کار می‌کند (تست‌شده)، ولی برای بعضی
  پست‌ها/استوری‌ها ورود به حساب می‌خواهد.
- دانلودهای خیلی طولانی (ویدیوی بلند) ممکن است از سقف حجم رد شوند و فقط نسخه صوتی فرستاده شود.
